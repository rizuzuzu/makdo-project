BASIC GITHUB ETTIQUETTE RULES

1. DO NOT edit the main branch directly pag mag cocommit kayo ng changes

2. always use your own branch - para hindi affected yung main source code incase may error kayo na add

<img width="612" height="584" alt="image" src="https://github.com/user-attachments/assets/9065002b-56d1-4118-a485-9fd9624f8774" />


3. test your code before you commit changes para walang error

4. do not delete or change someone else's code without asking 

6. tell the group if you encounter errors or if ur having issues
